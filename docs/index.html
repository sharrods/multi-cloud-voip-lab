// failover scenarios
🔴 Oracle Down
SRV records at carrier level point directly to GCP and AWS OpenSIPS. Calls bypass Oracle entirely — carriers resolve to whichever DC responds first. Zero manual intervention.
🟡 GCP or AWS Single Failure
Oracle detects the failed node and stops routing to it. Surviving DC absorbs 100% of traffic automatically. Load shifts without dropping active calls where possible.
⚫ Both GCP + AWS Down
Oracle plays emergency announcement — callers hear a service degradation message. No silent failures. Alertmanager fires to Slack, Gmail, and ntfy simultaneously.
🔵 IP Change Event
Learned the hard way — GCP free tier restart changed the IP. Required re-adding ACL rules in Azure, security groups in AWS, and Prometheus scrape targets. Now documented as a runbook.
